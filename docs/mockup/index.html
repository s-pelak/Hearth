How the palette maps

The grounds are the guide's ink and slate pushed darker, and text is mortar. The three accents keep their meaning from the whitepapers, so a glance at a thread list says what needs you.

TealWorking, primary buttons, the local model
CopperNeeds you, approvals, the flame, artifacts
BrickFailed, errors, anything that will cost money
SlateLabels, table heads, quiet structure

Settings live in the lower left. Escalation, file locations, models, and connectors and skills each get a page there, so the thread view stays clear. Escalation is off by default. When a local model stalls, the thread still offers a stronger model as a one-off button, priced up front.

Native on the Mac. Following Apple's Human Interface Guidelines, the app uses the system font, traffic lights in a unified title bar, a translucent sidebar, a real menu bar with ⌘ shortcuts, and a Settings window that ⌘, opens. It follows the system light or dark appearance and uses the brick, teal and copper only as accents. Windows gets the matching Fluent treatment (Mica, Segoe UI).
